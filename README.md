# 蒙西新能源多场站日清分与交易决策系统

面向蒙西发电侧新能源交易的 Streamlit 工具。支持多场站管理、批量上传日清分 Excel、96 点自动识别与 24 时点计算、日汇总入库、月度累计、结算扩展费用以及 P10/P50/P90 仓位交易决策。

## 功能

- 自助创建光伏/风电场站，并配置简称、装机容量和仓位风控参数
- 一次上传多个日清分 `.xlsx/.xlsm`
- 根据场站名称/简称/别名自动匹配场站，无法识别时可手工选择
- 自动识别交易日期和 96 点原始数据
- 96 个 15 分钟点转换为 24 个时点并计算日“总”
- SQLite 持久化保存；同场站+同日期防重复，可选择覆盖
- 按场站、月份累计电量、加权均价、收益、考核、风险防范等
- 决策模型读取真实累计结果，并叠加剩余 P10/P50/P90 发电预测
- 输出低发场景仓位、保守可售空间、建议卖出/买回量及边际毛收益

## 当前日清分模板

当前解析器按已确认的蒙西日清分模板读取：

- C：中长期电力
- D：中长期价格
- J：实时价格
- K：实际计量电力
- L：全网统一结算点价格

96 点按每 4 个 15 分钟点合成 1 个小时点。

小时计算：

- 中长期电量 = C 的 4 点平均
- 中长期价 = D 的 4 点平均
- 实际上网电量 = K 的 4 点平均
- 实时价 = J 按 K 加权；K 合计为 0 时使用 J 平均
- 统一结算点价 = L 的 4 点平均
- 现货电费 = 实际上网电量 × 实时价
- 中长期差价电费 = 中长期电量 × (中长期价 - 统一结算点价)
- 电能量合计 = 现货电费 + 中长期差价电费

月度价格采用电量加权，不对每日均价做简单算术平均。

## 本地运行

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
streamlit run app.py
```

数据库会在项目目录自动生成 `mengxi_trading.db`，已被 `.gitignore` 排除。

## 使用顺序

1. 在“场站管理”中新建场站。
2. 在“日清分上传”一次拖入一个或多个日清分文件。
3. 核对自动识别的场站和日期后入库。
4. 在“月度累计”查看截至最新日的累计统计。
5. 在“结算费用”维护考核、风险防范、机制、绿电等费用。
6. 在“交易决策”输入剩余月份 P10/P50/P90、已签合同和市场价格，获取仓位与交易建议。

## 重要说明

当前电能量日清分计算已按样表逻辑实现。考核、曲线合理度、风险防范、机制费用等最终规则尚未写死，应继续依据当期蒙西正式交易/结算规则逐项固化并做样单校验。决策模型属于交易风控辅助，不替代正式结算结果。
